# Supermarket Billing System

A Python project demonstrating all OOP concepts: Encapsulation, Inheritance, Polymorphism, Abstraction, Composition, and Design Patterns.

## Requirements
- Python 3.6+

## Installation
Save all 6 files in one folder:
- main.py
- product.py
- customer.py
- billing.py
- inventory.py
- payment.py

## Run
```bash
python main.py
```

## Quick Start
1. Start program → Press Enter
2. Select **2** (Start Shopping) → Enter `C001`
3. Select **6** (Add to Cart) → Product: `G001`, Qty: `2`
4. Select **8** (Generate Bill) → Coupon: `SAVE10`
5. Select **9** (Pay) → Method: `3` (UPI) → ID: `customer@paytm`

## Features
- Product management (4 categories)
- Customer & Membership system
- Shopping cart & billing
- Multiple payment methods
- Inventory reports
